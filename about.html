About This Project

A small website for learning web development and GitHub collaboration.

Technologies

  • HTML defines the structure and content of each page.
  • CSS controls colors, spacing, and the appearance of the website.
  • JavaScript adds interaction, such as the welcome message on the home page.

My Contribution
